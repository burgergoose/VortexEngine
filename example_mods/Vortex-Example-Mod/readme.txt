example mod

a small mod with one week, one song, one character, one stage and one event so you can see how a mod is set up.
copy the folder, rename it and swap the files for your own. you can delete it or turn it off in the mods menu.

weeks/ - the week file
data/<song>/ - the chart
songs/<song>/ - Inst.ogg and Voices.ogg (or Voices-Player.ogg + Voices-Opponent.ogg), .wav works too but not .mp3
characters/ - character json, the picture goes in images/characters/
stages/ - stage json
custom_events/ - event txt + lua

songs that have a chart but no week file still show up in freeplay.
